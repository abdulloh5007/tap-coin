# Tap Coin

Минималистичное realtime-приложение: цена монеты живёт от тапов людей.

Стартовая цена: `0.000000001`. Тап — это бензин. Лидерборда пока нет.

## Как устроено

- **Цена** растёт в каждом тике (250 мс), если кто-то тапает. Чем больше уникальных людей жмут в этот момент, тем сильнее рост. Если тапов нет — цена медленно падает, но не ниже старта.
- **Бензин за тап** не фиксирован. Чем больше людей тапают одновременно, тем меньше бензина получает каждый тап: `1 / sqrt(активные) × множитель окна`.
- **Окна суток (UTC)**
  - `00–08` затишье ×0.5
  - `08–16` норма ×1.0
  - `16–24` пик ×1.75
- Тапы копятся в памяти и применяются пачкой на тике. На человека — не больше 10 тапов за тик, чтобы пик нагрузки не ломал сервер. Счётчики тапов и бензина пишутся в SQLite одной транзакцией тика.

## Запуск

```bash
npm install
npm run dev
```

Клиент: http://localhost:5173  
API / WS: http://localhost:3001

Нужны Node.js 22+ (встроенный SQLite).

```bash
npm test
npm run build
npm start   # сервер + собранный клиент на :3001
```
